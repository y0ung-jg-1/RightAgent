# RightAgent v1.0.2

## 中文说明

本次发布改进了 RightAgent 的安装体验和设置窗口在较小尺寸下的可用性，并统一了中文与英文发布文档。v1.0.2 起，GitHub Release 直接提供单文件安装器，不再要求用户下载并解压 ZIP 安装包。

### 本版更新

- 正式发布包改为单个 `RightAgent-1.0.2-x64-Setup.exe`，另附 SHA-256 校验文件。安装器内含已签名的 MSIX、x64 VCLibs 依赖和 RightAgent 公共证书。
- 安装器会在启动时请求管理员批准，只在管理员阶段验证软件包并把公共证书加入“本地计算机\受信任的人”，随后切回最初发起安装的 Windows 用户完成 MSIX 安装。
- 修复设置窗口缩窄时内容左右错位或被裁切的问题。窗口现在具有合理的最小尺寸，并会在可用宽度不足时隐藏右侧菜单预览，让主要设置区域保持完整可用。
- 中文与英文的自述文件和侧载安装文档现已完全分开；发布工作流也会强制使用版本对应的完整中英文发布说明。

### 安装方法

1. 下载 `RightAgent-1.0.2-x64-Setup.exe` 和同名 `.sha256` 文件。
2. 核对 SHA-256 后双击安装器，并批准用户账户控制提示。
3. 安装完成后，右键文件夹或文件夹空白处即可使用 RightAgent。若资源管理器仍缓存旧菜单，请关闭全部资源管理器窗口或注销一次。

### 系统要求

- Windows 11 x64，系统版本 22000 或更新。
- Windows Terminal。设置应用在未检测到 Windows Terminal 时会提供 Microsoft Store 安装入口。

### 安全信息

- 安装器和内嵌 MSIX 均带有签名与 RFC 3161 时间戳。
- 安装器只携带公共证书，不包含 PFX、密码或私钥。
- 当前发布证书为项目自签名证书，因此干净电脑首次显示用户账户控制提示时可能标注“未知发布者”。请只从官方 GitHub Release 下载，并在安装前核对 SHA-256。

本版本仍只注册 Windows 11 新右键菜单；经典“显示更多选项”菜单不在本版范围内。

## English release notes

This release improves RightAgent's installation experience and keeps the settings window usable at smaller sizes. It also separates Chinese and English release documentation consistently. Starting with v1.0.2, GitHub Releases provide a single-file installer instead of requiring users to download and extract a ZIP bundle.

### Changes in this release

- The public release payload is now one `RightAgent-1.0.2-x64-Setup.exe` plus its SHA-256 file. Setup contains the signed MSIX, x64 VCLibs dependencies, and the public RightAgent certificate.
- Setup requests administrator approval at startup. Its elevated phase only validates the package and adds the public certificate to Local Computer\Trusted People, then switches back to the Windows user who started Setup to install the MSIX.
- Fixed settings content shifting horizontally or being clipped when the window was narrowed. The window now has a practical minimum size and hides the right-side menu preview when space is limited, keeping the main settings area usable.
- The Chinese and English README and sideload installation guides are now fully separated. The release workflow also requires complete version-specific notes in both languages.

### Installation

1. Download `RightAgent-1.0.2-x64-Setup.exe` and its matching `.sha256` file.
2. Verify the SHA-256, run Setup, and approve the User Account Control prompt.
3. After installation, right-click a folder or folder background to use RightAgent. If File Explorer still caches an old menu, close all File Explorer windows or sign out once.

### Requirements

- Windows 11 x64, build 22000 or newer.
- Windows Terminal. If the settings app cannot find Windows Terminal, it offers the Microsoft Store installation entry.

### Security information

- Both Setup and the embedded MSIX carry signatures and RFC 3161 timestamps.
- Setup contains only the public certificate, never the PFX, password, or private key.
- The project currently uses a self-signed release certificate, so User Account Control can show “Unknown publisher” on a clean PC. Download only from the official GitHub Release and verify the SHA-256 before installation.

This version still registers only the modern Windows 11 context menu. Classic “Show more options” integration is not included.

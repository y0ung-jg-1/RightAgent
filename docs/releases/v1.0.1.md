# RightAgent v1.0.1

## 中文说明

RightAgent 的首个公开版本，把 AI 编程助手加入 Windows 11 新右键菜单。可以在 WinUI 3 设置应用中统一管理菜单模式、助手顺序、命令、网址、图标、界面语言、命令解释器和 Windows Terminal 配置文件。

### 本版更新

- 新增独立的命令解释器设置。自动模式优先使用 PowerShell 7，未安装时回退到 Windows PowerShell 5.1；也可以明确选择 PowerShell 7、Windows PowerShell 5.1 或 CMD。
- 修正 Windows Terminal 的命令传递方式，使复杂参数、引号和分号能够安全传递。
- 设置应用启动时会检测 Windows Terminal；未安装时会说明原因，并提供 Microsoft Store 安装入口。
- 设置结构保持向后兼容，旧配置会自动采用安全的 `auto` 模式。

### 主要功能

- 支持分组子菜单和单个助手直达两种模式。
- 支持本地图标、自定义助手、双语界面和实时预览。
- 没有托盘进程、后台服务、遥测或自动更新。
- RightAgent 源码以 MIT 许可证开源。

### 安装方法

系统要求：Windows 11 x64，系统版本 22000 或更新。终端动作需要 Windows Terminal；若尚未安装，RightAgent 会提供 Microsoft Store 安装入口。

1. 下载 `RightAgent-1.0.1-x64.zip` 和 `RightAgent-1.0.1-x64.zip.sha256`。
2. 核对 ZIP 的 SHA-256：

   `e36ffe7d12da53329b3be93be5f14ee39b71aa61c8ba93e2f0a7152f56518e30`

3. 完整解压 ZIP，检查内容后运行 `Install-RightAgent.ps1`。首次安装会请求管理员批准，将包内的项目公共证书导入“本地计算机\受信任的人”证书存储。

### 安全信息

- MSIX 签名者：`CN=RightAgent`
- 证书指纹：`776E9003DC223A17623E8482844030D5F07FB76F`
- 签名包含 DigiCert SHA-256 RFC 3161 时间戳。
- 发布包只包含公共 CER，不包含 PFX、密码或私钥。

### 当前范围

v1.0.1 仅注册 Windows 11 新右键菜单；经典“显示更多选项”菜单不在本版范围内。

## English release notes

RightAgent's first public release adds AI coding agents to the modern Windows 11 context menu. The WinUI 3 settings app manages the menu mode, agent order, commands, URLs, icons, interface language, command shell, and Windows Terminal profile.

### Changes in this release

- Added an independent command-shell setting. Automatic mode prefers PowerShell 7 and falls back to Windows PowerShell 5.1; PowerShell 7, Windows PowerShell 5.1, and CMD can also be selected explicitly.
- Hardened Windows Terminal command transport so complex arguments, quotes, and semicolons are passed safely.
- The settings app now detects a missing Windows Terminal installation, explains the requirement, and offers the official Microsoft Store entry.
- Existing settings remain compatible and default to the safe `auto` mode.

### Highlights

- Grouped submenu and direct-agent modes.
- Local icons, custom agents, a bilingual interface, and live preview.
- No tray process, background service, telemetry, or automatic updater.
- RightAgent source is released under the MIT License.

### Installation

Requirements: Windows 11 x64, build 22000 or newer. Terminal actions require Windows Terminal. RightAgent offers the Microsoft Store entry if it is missing.

1. Download `RightAgent-1.0.1-x64.zip` and `RightAgent-1.0.1-x64.zip.sha256`.
2. Verify the ZIP SHA-256:

   `e36ffe7d12da53329b3be93be5f14ee39b71aa61c8ba93e2f0a7152f56518e30`

3. Extract the complete ZIP, inspect its contents, and run `Install-RightAgent.ps1`. The first installation requests administrator approval to import the bundled project public certificate into the Local Computer\Trusted People certificate store.

### Security information

- MSIX signer: `CN=RightAgent`
- Certificate thumbprint: `776E9003DC223A17623E8482844030D5F07FB76F`
- The signature includes a DigiCert SHA-256 RFC 3161 timestamp.
- The release bundle contains only the public CER, never the PFX, password, or private key.

### Current scope

v1.0.1 targets only the modern Windows 11 context menu. Classic “Show more options” integration is not included.

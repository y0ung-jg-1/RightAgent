# v1.1.3

## 中文说明

本次发布修复“多个直达”模式下右键菜单先出现大约 16 条“正在加载…”，再慢慢收成实际 Agent 的问题。Windows 11 会为每一个已注册的命令包先画出占位项；现在设置应用只会保留当前模式真正需要的命令包，因此菜单不再为用不到的槽位闪出加载项。

### 本版更新

- 修复多个直达模式右键时先出现约 16 条“正在加载…”，随后逐条消失、只留下已启用 Agent 的问题。
- 设置应用会按当前菜单模式同步命令包占用：菜单关闭时不注册命令包，分组或单个直达只保留 1 个，多个直达只保留已启用 Agent 的数量。
- 安装器仍内嵌全部 16 个命令 MSIX，并写入主程序 `LocalState/CommandPackages` 缓存，切换模式或增减 Agent 时可以再注册回来。
- 隐藏槽位不再返回标题或图标，避免 Explorer 在卸载完成前把占位项显示成“使用 RightAgent 打开”。
- 修复保存设置时因跨线程释放互斥锁而提示“保存失败”的问题；设置文件会先写入，命令包同步在同一后台线程完成。
- 安装器和设置应用在命令包占用变化后会刷新资源管理器，避免 Windows 11 继续画出已卸载槽位的“正在加载…”占位项。
- 升级到 v1.1.3 后请打开一次 RightAgent 设置（或再保存一次）。任务栏可能会闪一下，随后右键菜单应按当前启用的 Agent 直接出现。

### 安装方法

1. 下载 `RightAgent-1.1.3-x64-Setup.exe` 和同名 `.sha256` 文件。
2. 核对 SHA-256 后双击安装器。首次安装若证书尚未受信任，请按提示批准一次用户账户控制请求。
3. 安装完成后打开一次 RightAgent 设置。随后右键文件夹或文件夹空白处即可使用；若资源管理器仍缓存旧菜单，请关闭全部资源管理器窗口或注销一次。

### 系统要求

- Windows 11 x64，系统版本 22000 或更新。
- Windows Terminal。设置应用在未检测到 Windows Terminal 时会提供 Microsoft Store 安装入口。

### 安全信息

- 安装器和内嵌 MSIX 均应带有签名与 RFC 3161 时间戳。
- 安装器只携带公共证书，不包含 PFX、密码或私钥。
- 当前发布证书为项目自签名证书，因此干净电脑首次运行安装器时可能显示未知发布者提示。请只从官方 GitHub Release 下载，并在安装前核对 SHA-256。

本版本仍只注册 Windows 11 新右键菜单；经典“显示更多选项”菜单不在本版范围内。

## English release notes

This release stops multi-direct mode from flashing about 16 “Loading…” placeholders that then shrink to the enabled agents. Windows 11 draws a placeholder for every registered command package before it queries state. The settings app now keeps only the command packages required by the current menu mode, so unused slots never appear in the menu.

### Changes in this release

- Fixed multi-direct right-clicks showing roughly 16 “Loading…” items that then disappeared one by one until only the enabled agents remained.
- The settings app now synchronizes command-package occupancy with the saved menu mode: none when the menu is off, one package for grouped or single-direct, and one package per enabled agent in multi-direct.
- Setup still embeds all 16 command MSIX packages and copies them into the main package `LocalState/CommandPackages` cache so later mode or agent changes can register missing slots again.
- Hidden slots no longer return a title or icon, so Explorer cannot briefly advertise unused commands as “Open with RightAgent”.
- Fixed a save failure caused by releasing a named mutex from a different thread after an await. Settings are written first; command-package occupancy now runs on one background thread.
- Setup and the settings app now refresh Explorer after command-package occupancy changes, so Windows 11 does not keep painting “Loading…” placeholders for removed slots.
- After upgrading to v1.1.3, open RightAgent settings once (or save again). The taskbar may flicker once; the next right-click should show only the currently enabled agents.

### Installation

1. Download `RightAgent-1.1.3-x64-Setup.exe` and its matching `.sha256` file.
2. Verify the SHA-256 and run Setup. If the certificate is not trusted yet, approve the one-time User Account Control prompt.
3. Open RightAgent settings once after installation. Then right-click a folder or folder background to use RightAgent. If File Explorer still shows a cached menu, close all Explorer windows or sign out once.

### Requirements

- Windows 11 x64, build 22000 or newer.
- Windows Terminal. If the settings app cannot find Windows Terminal, it offers the Microsoft Store installation entry.

### Security information

- Both Setup and the embedded MSIX should carry signatures and RFC 3161 timestamps.
- Setup contains only the public certificate, never the PFX, password, or private key.
- The current release certificate is project-owned and self-signed, so a clean PC may show an unknown-publisher prompt on first run. Download only from the official GitHub Release and verify the SHA-256 before installing.

This version still registers only the modern Windows 11 context menu. Classic “Show more options” integration is not included.

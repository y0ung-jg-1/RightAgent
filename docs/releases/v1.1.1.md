# v1.1.1

## 中文说明

本次发布加入 Cursor Agent 内置支持。安装 Cursor Agent CLI 后，RightAgent 会自动检测 `cursor-agent` 命令，并允许在分组菜单、单个直达或多个直达模式中从当前文件夹启动它。

### 本版更新

- 新增 Cursor Agent 内置项，激活命令固定为 `cursor-agent`，并兼容其默认的按用户安装目录。
- 新增来自 Lobe Icons 的 Cursor 本地图标；SVG 与多分辨率 ICO 均随应用打包，运行时不会联网获取。
- 已有设置会在首次打开 v1.1.1 设置应用时自动补入并保存 Cursor Agent；只有检测到 `cursor-agent` 命令时才会默认启用，用户原有设置不会被重置。
- 修复 v1.1.0 中“多个直达 Agent”仍显示为单个 RightAgent 命令或 `RightAgent` 浮出菜单的问题；每个已启用 Agent 现在使用独立归属的 Windows 11 根菜单命令。
- 单文件 Setup 安装器现在会在内部部署 1 个主程序包和 16 个隐藏命令包，以满足 Windows 11 的菜单归属规则；下载与安装入口仍然只有一个 EXE，开始菜单也只显示一个 RightAgent。
- 修复设置应用与资源管理器 COM 代理可能读取不同设置文件的问题；两者现在统一使用同一个 MSIX `LocalState`。
- 托管默认值、原生右键菜单、设置界面图标解析、打包检查和自动化测试已同步覆盖 Cursor Agent。

### 安装方法

1. 下载 `RightAgent-1.1.1-x64-Setup.exe` 和同名 `.sha256` 文件。
2. 核对 SHA-256 后双击安装器。首次安装若证书尚未受信任，请按提示批准一次用户账户控制请求。
3. 安装 Cursor Agent CLI 并确保 `cursor-agent` 可在终端中执行。打开 RightAgent 后即可启用或调整 Cursor Agent。

### 系统要求

- Windows 11 x64，系统版本 22000 或更新。
- Windows Terminal。设置应用在未检测到 Windows Terminal 时会提供 Microsoft Store 安装入口。

本版本仍只注册 Windows 11 新右键菜单；经典“显示更多选项”菜单不在本版范围内。

## English release notes

This release adds built-in Cursor Agent support. After the Cursor Agent CLI is installed, RightAgent detects the `cursor-agent` command and can launch it in the current folder from grouped, single-direct, or multiple-direct menu mode.

### Changes in this release

- Added a built-in Cursor Agent entry with the exact activation command `cursor-agent`, including its default per-user installation directory.
- Added a local Cursor icon from Lobe Icons. Both the SVG and multi-resolution ICO are packaged with the app and are never fetched at runtime.
- Existing settings automatically gain and persist the Cursor Agent entry when the v1.1.1 settings app is first opened. It is enabled by default only when the `cursor-agent` command is detected, and existing user settings are preserved.
- Fixed v1.1.0 multi-direct mode still appearing as one RightAgent command or a `RightAgent` flyout. Every enabled agent now uses a separately attributed Windows 11 root-menu command.
- The single-file Setup now deploys one main package and 16 hidden command packages internally to satisfy Windows 11 command-attribution rules. There is still only one EXE to download and one visible RightAgent entry in Start.
- Fixed a settings-path mismatch that could make the settings app and Explorer COM surrogate read different files; both now use the same MSIX `LocalState`.
- Managed defaults, the native context menu, settings-app icon resolution, package checks, and automated tests now cover Cursor Agent.

### Installation

1. Download `RightAgent-1.1.1-x64-Setup.exe` and its matching `.sha256` file.
2. Verify the SHA-256 and run Setup. If the certificate is not trusted yet, approve the one-time User Account Control prompt.
3. Install the Cursor Agent CLI and confirm that `cursor-agent` runs in a terminal. Open RightAgent to enable or arrange Cursor Agent.

### Requirements

- Windows 11 x64, build 22000 or newer.
- Windows Terminal. If the settings app cannot find Windows Terminal, it offers the Microsoft Store installation entry.

This version still registers only the modern Windows 11 context menu. Classic “Show more options” integration is not included.

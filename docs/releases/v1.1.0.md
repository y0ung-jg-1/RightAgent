# v1.1.0

## 中文说明

本次发布新增“多个直达 Agent”菜单模式，并改进单文件安装器的权限边界、可靠性和安装进度展示。用户现在可以把多个已启用 Agent 按设置顺序直接放到 Windows 11 右键菜单根目录，同时继续使用原有的分组菜单或单个 Agent 直达模式。

### 本版更新

- 新增“多个直达 Agent”模式：每个已启用 Agent 都会成为右键菜单根目录中的独立命令，并沿用设置中的排列顺序、名称、图标和动作。
- 设置应用增加第三种菜单模式及对应实时预览；托管与原生设置校验、兼容性回退和测试范围同步更新。
- 安装器现在始终以当前 Windows 用户运行，只在首次信任随包公共证书时单独请求管理员批准；证书已受信任的升级不再重复请求管理员权限。
- MSIX 部署阶段显示 Windows 返回的真实安装百分比，并加强并发安装防护、错误处理和 GitHub Actions 安装冒烟测试。
- GitHub Release 标题统一只使用版本号，例如 `v1.1.0`。

### 安装方法

1. 下载 `RightAgent-1.1.0-x64-Setup.exe` 和同名 `.sha256` 文件。
2. 核对 SHA-256 后双击安装器。首次安装若证书尚未受信任，请按提示批准一次用户账户控制请求。
3. 安装完成后，右键文件夹或文件夹空白处即可使用 RightAgent。若资源管理器仍缓存旧菜单，请关闭全部资源管理器窗口或注销一次。

### 系统要求

- Windows 11 x64，系统版本 22000 或更新。
- Windows Terminal。设置应用在未检测到 Windows Terminal 时会提供 Microsoft Store 安装入口。

### 安全信息

- 安装器和内嵌 MSIX 均应带有签名与 RFC 3161 时间戳。
- 安装器只携带公共证书，不包含 PFX、密码或私钥。
- 当前发布证书为项目自签名证书，因此干净电脑首次运行安装器时可能显示未知发布者提示。请只从官方 GitHub Release 下载，并在安装前核对 SHA-256。

本版本仍只注册 Windows 11 新右键菜单；经典“显示更多选项”菜单不在本版范围内。

## English release notes

This release adds a multiple-direct-agents menu mode and improves the single-file installer's privilege boundary, reliability, and progress reporting. Multiple enabled agents can now appear directly at the root of the Windows 11 context menu in settings order, while the existing grouped submenu and single-direct-agent modes remain available.

### Changes in this release

- Added a multiple-direct-agents mode. Every enabled agent becomes an independent root-level context-menu command and retains its configured order, name, icon, and action.
- Added the third menu mode and its live preview to the settings app, with matching managed and native validation, compatibility fallback, and test coverage.
- Setup now remains under the current Windows user and requests administrator approval only when the bundled public certificate must be trusted for the first time. Upgrades do not elevate again while the certificate remains trusted.
- The MSIX deployment phase displays the real percentage reported by Windows, with stronger concurrent-install protection, error handling, and a GitHub Actions installation smoke test.
- GitHub Release titles now contain only the version, such as `v1.1.0`.

### Installation

1. Download `RightAgent-1.1.0-x64-Setup.exe` and its matching `.sha256` file.
2. Verify the SHA-256 and run Setup. If the certificate is not trusted yet, approve the one-time User Account Control prompt.
3. After installation, right-click a folder or folder background to use RightAgent. If File Explorer still caches an old menu, close all File Explorer windows or sign out once.

### Requirements

- Windows 11 x64, build 22000 or newer.
- Windows Terminal. If the settings app cannot find Windows Terminal, it offers the Microsoft Store installation entry.

### Security information

- Both Setup and the embedded MSIX should carry signatures and RFC 3161 timestamps.
- Setup contains only the public certificate, never the PFX, password, or private key.
- The project currently uses a self-signed release certificate, so Windows can show an unknown-publisher warning when Setup first runs on a clean PC. Download only from the official GitHub Release and verify the SHA-256 before installation.

This version still registers only the modern Windows 11 context menu. Classic “Show more options” integration is not included.

# RightAgent v1.3.0

## 中文说明

这次发布清理设置应用和启动链路里搬迁解包安装后没拆完的部分：自定义图标按真实用户目录显示，读设置失败不再覆盖用户文件，命令检测和启动不再误用打包重定向的 AppData。

### 本版更新

- 自定义图标写在 `%LOCALAPPDATA%\RightAgent\Icons`，设置界面用文件路径预览，换图会立刻刷新。
- 删掉的内置 Agent 不会在下次打开设置时自动加回来。
- 设置文件被占用或暂时读失败时，不再当成损坏并写成默认配置。
- 从资源管理器启动时，命令探测和 Windows Terminal 使用真实的用户 LocalAppData，而不是命令包的 LocalCache。
- 设置应用用 Windows 部署 API 同步命令包，不再另外拉起 PowerShell。
- 不再写出已停用的 `terminalShell` 字段；旧文件仍能读。
- 自定义图标可以改回内置；直达模式下拉只列出已启用的 Agent。
- 公开 Release 只提供本机 `RightAgent-1.3.0-x64-Setup.exe`。普通 CI 也会编出未签名的 Setup。
- 安装器工具链改为 WiX 7。

### 安装方法

1. 下载 `RightAgent-1.3.0-x64-Setup.exe` 和同名 `.sha256` 文件。
2. 核对 SHA-256 后双击安装器；首次安装时按提示批准用户账户控制请求。

### 安全信息

- 安装器和内嵌 MSIX 均应带有签名与 RFC 3161 时间戳。
- 安装器只携带公共证书，不包含 PFX、密码或私钥。

## English release notes

This release finishes the unpackaged-settings move: custom icons preview from the real user directory, a locked settings file is no longer treated as corrupt, and Explorer launches no longer inherit a packaged AppData hive.

### Changes in this release

- Custom icons live under `%LOCALAPPDATA%\RightAgent\Icons` and preview from that file path, including after replacing an icon.
- Deleted built-in agents stay deleted.
- A sharing or I/O failure no longer rewrites `settings.json` with defaults.
- Command detection and Windows Terminal inherit the real user LocalAppData, not the command package LocalCache.
- Occupancy sync uses the Windows deployment API instead of launching PowerShell from the settings app.
- Writers omit the unused `terminalShell` field; older files still load.
- Custom icons can be reset to the built-in asset. The direct-mode list only shows enabled agents.
- The public Release publishes only the per-machine `RightAgent-1.3.0-x64-Setup.exe`. Ordinary CI also compiles an unsigned Setup.
- The installer toolchain is WiX 7.

### Installation

1. Download `RightAgent-1.3.0-x64-Setup.exe` and its matching `.sha256` file.
2. Verify the SHA-256 and run Setup. Approve the User Account Control prompt on first installation.

### Security information

- Both Setup and the embedded MSIX should carry signatures and RFC 3161 timestamps.
- Setup contains only the public certificate, never the PFX, password, or private key.

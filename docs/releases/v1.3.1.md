# RightAgent v1.3.1

## 中文说明

这次发布修设置保存和资源管理器占用同步里的几处正确性问题：无效字段不再改已安装的命令包，资源管理器读到的设置更接近设置应用写出的结果，关窗保存时也不再在后台线程改界面绑定。

### 本版更新

- 只有真正写到磁盘的设置才会同步资源管理器命令包。字段无效时关窗，占用保持上一份有效设置。
- 表单变成无效会取消尚未执行的自动保存，避免把 Normalize 后的快照悄悄写盘，而界面仍显示错误字段。
- 快速切换菜单模式或启用的 Agent 时，占用同步会串行重算，降低留下多余“正在加载…”占位项的机会。
- 资源管理器侧的设置解析与设置应用对齐：无法作为绝对地址解析的 `http`/`https` URL，以及空的 `local:` 图标，都会按同样规则处理。
- 保存时修正直达 Agent 不再在后台线程改 WinUI 绑定集合，避免关窗或保存后界面错乱。
- 公开 Release 只提供本机 `RightAgent-1.3.1-x64-Setup.exe`。升级保留 `%LOCALAPPDATA%\RightAgent\settings.json`。

### 安装方法

1. 下载 `RightAgent-1.3.1-x64-Setup.exe` 和同名 `.sha256` 文件。
2. 核对 SHA-256 后双击安装器；首次安装时按提示批准用户账户控制请求。

### 安全信息

- 安装器和内嵌 MSIX 均应带有签名与 RFC 3161 时间戳。
- 安装器只携带公共证书，不包含 PFX、密码或私钥。

## English release notes

This release fixes settings persist and Explorer occupancy: invalid fields no longer change installed command packages, native settings parse closer to what the settings app writes, and persist-side UI repair no longer mutates bindings on a worker thread.

### Changes in this release

- Occupancy sync follows only the settings snapshot that reached disk. Closing the window with invalid fields keeps the last valid installed slots.
- Becoming invalid cancels a pending autosave, so Normalize cannot write a repaired snapshot while the UI still shows the bad field.
- Rapid menu-mode or agent changes re-plan occupancy under the installation mutex, which reduces leftover Explorer “Loading…” placeholders.
- Native settings parse matches the settings writer for `http`/`https` URLs that fail an absolute URI parse and for empty `local:` icon paths.
- Persist-side direct-agent repair no longer mutates WinUI-bound collections on a worker thread.
- The public Release publishes only the per-machine `RightAgent-1.3.1-x64-Setup.exe`. An upgrade keeps `%LOCALAPPDATA%\RightAgent\settings.json`.

### Installation

1. Download `RightAgent-1.3.1-x64-Setup.exe` and its matching `.sha256` file.
2. Verify the SHA-256 and run Setup. Approve the User Account Control prompt on first installation.

### Security information

- Both Setup and the embedded MSIX should carry signatures and RFC 3161 timestamps.
- Setup contains only the public certificate, never the PFX, password, or private key.

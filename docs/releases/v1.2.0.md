# v1.2.0

## 中文说明

本次发布把设置应用改成解包安装，并用和 PowerToys 一样的 WiX Burn 单文件 `Setup.exe` 分发。上一份公开 Release 仍是 v1.1.1；仓库里曾准备过但未打标签的 v1.1.3 / v1.1.4 也一并包含。安装后右键菜单应能直接出现当前启用的 Agent，设置窗口在高 DPI 屏幕上应按逻辑像素打开并居中，点关闭不应再卡住。

### 本版更新

- 设置应用改为解包的 WinUI 程序，默认装到 `%ProgramFiles%\RightAgent`；设置和命令包缓存改为 `%LOCALAPPDATA%\RightAgent`。
- 公开安装器改为 WiX 5 Burn `RightAgent-1.2.0-x64-Setup.exe`（本机）。另有 `UserSetup.exe` 供当前用户安装。Inno Setup 已停用。
- 安装器界面跟随 Windows 显示语言（简体中文 / 英文）。
- 设置界面改为系统设置风格的分页、分区标题和自动保存。
- 终端操作改为沿用所选 Windows Terminal 配置文件的 shell，不再单独挑选 PowerShell / CMD。
- 设置窗口默认 1150×720 DIP，按显示器 DPI 换算，并在当前工作区居中；高缩放屏幕上不再锁死成一组物理像素。
- 中间设置栏会用掉剩余宽度，宽度够时显示右侧菜单预览；Agent 开关与标题保持同一行，直到这一行真正摆不下。
- 修复安装后右键没有菜单：命令包不再误读打包虚拟化目录，也能解析 PowerShell 5 写出的带 BOM 的 `install.json`。
- 修复设置窗口点右上角关闭后卡住的问题。
- 修复 PowerShell 7 把启动参数整段当成脚本路径、无法打开 Agent 的问题。
- 修复安装器在多个直达下只注册第一个命令槽的问题；设置应用补注册改用 Windows PowerShell 5 支持的 `Add-AppxPackage -Path`，并按用户配置目录读取设置。
- 多个直达模式仍按占用注册命令包；缓存里已有的槽位会补注册，避免只剩第一个 Agent。避免再出现约 16 条“正在加载…”占位项。

### 安装方法

1. 下载 `RightAgent-1.2.0-x64-Setup.exe` 和同名 `.sha256` 文件。
2. 核对 SHA-256 后双击安装器，按提示批准用户账户控制请求。
3. 安装完成后，右键文件夹或文件夹空白处即可使用。若刚从旧版升级，请先关掉已卡住的设置窗口，再开一次设置或新开一个资源管理器窗口。

### 系统要求

- Windows 11 x64，系统版本 22000 或更新。
- Windows Terminal。设置应用在未检测到 Windows Terminal 时会提供 Microsoft Store 安装入口。

### 安全信息

- 安装器和内嵌 MSIX 均应带有签名与 RFC 3161 时间戳。
- 安装器只携带公共证书，不包含 PFX、密码或私钥。
- 当前发布证书为项目自签名证书，因此干净电脑首次运行安装器时可能显示未知发布者提示。请只从官方 GitHub Release 下载，并在安装前核对 SHA-256。

本版本仍只注册 Windows 11 新右键菜单；经典“显示更多选项”菜单不在本版范围内。

## English release notes

This release ships the settings app unpackaged and distributes it with a PowerToys-style WiX Burn `Setup.exe`. The last public GitHub Release is still v1.1.1; occupancy and installer work prepared for untagged v1.1.3 / v1.1.4 is included. After Setup, the context menu should show the enabled agents, the settings window should open at a DPI-aware size centered on the work area, and it should close from the title-bar close button.

### Changes in this release

- The settings app is now an unpackaged WinUI build installed to `%ProgramFiles%\RightAgent` by default. Settings and the command-package cache live under `%LOCALAPPDATA%\RightAgent`.
- The public installer is a WiX 5 Burn `RightAgent-1.2.0-x64-Setup.exe` (per-machine). `UserSetup.exe` is the per-user SKU. Inno Setup is retired.
- The Setup UI follows the Windows display language (Simplified Chinese or English).
- Settings now use a Windows Settings-style paged layout with section headers and auto-save.
- Terminal actions keep the selected Windows Terminal profile’s shell instead of picking PowerShell or CMD separately.
- The settings window defaults to 1150×720 DIP, scaled by display DPI, and is centered on the current work area instead of locking a physical pixel size.
- The settings column uses leftover width, the live preview appears when it fits, and agent toggles stay on the header row until that row is actually full.
- Fixed a post-install empty context menu: command packages now read the real user settings directory, not the packaged LocalCache redirect, and they accept a UTF-8 BOM on `install.json` from Windows PowerShell 5.
- Fixed the settings window hanging when closed from the title-bar close button.
- Fixed PowerShell 7 treating the launch suffix as a script path, which prevented agents from starting.
- Fixed Setup registering only the first command slot in multi-direct mode. Occupancy repair now uses `Add-AppxPackage -Path` (compatible with Windows PowerShell 5) and reads settings from the user's profile directory.
- Multi-direct mode still registers only the required command packages, and now adds any missing slots that are already in the cache so the menu is not left with only the first agent. Explorer no longer flashes about 16 “Loading…” placeholders.

### Installation

1. Download `RightAgent-1.2.0-x64-Setup.exe` and its matching `.sha256` file.
2. Verify the SHA-256 and run Setup. Approve the User Account Control prompt.
3. After installation, right-click a folder or folder background. If you are upgrading from an older build, close any stuck settings window first, then open settings once or open a new File Explorer window.

### Requirements

- Windows 11 x64, build 22000 or newer.
- Windows Terminal. If the settings app cannot find Windows Terminal, it offers the Microsoft Store installation entry.

### Security information

- Both Setup and the embedded MSIX should carry signatures and RFC 3161 timestamps.
- Setup contains only the public certificate, never the PFX, password, or private key.
- The current release certificate is project-owned and self-signed, so a clean PC may show an unknown-publisher prompt on first run. Download only from the official GitHub Release and verify the SHA-256 before installing.

This version still registers only the modern Windows 11 context menu. Classic “Show more options” integration is not included.
